Vertex AI Gemini Flex Mode
Flex PayGo: Reduces Google Vertex AI token costs by 50% for Gemini models by sending dynamic routing headers (X-Vertex-AI-LLM-Shared-Request-Type: flex) and directing traffic to the global endpoint. Works in both Express Mode (API Key) and Full Mode (Service Account JSON).

Model Compatibility: Supported on Gemini Flash and Standard Pro models (e.g. gemini-3.8-flash). Frontier reasoning models (e.g. gemini-4-argon) are unsupported by Google Vertex Flex and are automatically bypassed to prevent API errors.
Flex tier provides 50% discount on input/output tokens with variable latency. Priority tier provides highest reliability.
Recommended: Google Vertex AI requires requests to target locations/global for Flex PayGo. Automatically rewrites request region to global.
Displays an interactive status indicator and quick-toggle directly below the Google Model dropdown in the Vertex AI configuration form.
Automatically bypasses Flex headers for models like gemini-4-argon (which support Flex on Google AI Studio but are not yet enabled for Flex PayGo on Google Cloud Vertex AI), preventing flex api is not supported errors. Uncheck if Google enables Vertex Flex for Argon.
